# Pet gallery

Browse every published pet at native sprite size. Select a pet to open all nine runtime movements plus its complete sixteen-direction look sheet.

Every GIF in this gallery is deterministically rendered from the final despilled v2 atlas. Primary packages are installable releases; experimental packages are private-preview-quality builds retained for testing and motion-template research.
