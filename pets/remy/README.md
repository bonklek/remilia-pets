# Remy

Remy is a relaxed, loyal, quietly mischievous rough-crayon neochibi companion.

## Package

- ID: `remy`
- Sprite version: `2`
- Atlas: `1536×2288` WebP with alpha
- Cell size: `192×208`
- Layout: `8×11`

Keep `pet.json` and `spritesheet.webp` together when installing or sharing the package.
