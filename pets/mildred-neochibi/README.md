# Mildred

Mildred is a custom Codex v2 pet wearing a vampire costume, with green hair, an oversized blue bow, rosy cheeks, and a dark cape-like outfit.

## Package

- ID: `mildred-neochibi`
- Sprite version: `2`
- Atlas: `1536×2288` WebP with alpha
- Cell size: `192×208`
- Layout: `8×11`

Keep `pet.json` and `spritesheet.webp` together when installing or sharing the package.
